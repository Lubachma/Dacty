# Plan d'implémentation : interface bilingue fr/en (i18n)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** rendre toute l'interface de Dacty bilingue fr/en (défaut : détection navigateur, anglais sinon), sans nouvelle dépendance.

**Architecture:** module `src/i18n/` maison : dictionnaires typés (`fr.ts` source des clés, `en.ts` vérifié par le compilateur), `translate()` pur, hooks `useT()`/`useUiLanguage()` adossés à `useSettings`. La langue d'interface est un nouveau champ de profil `uiLanguage`, persisté en IndexedDB, détectée via `navigator.language` quand absente. Les succès portent des objets `{ fr, en }` (`LocalizedText`).

**Tech Stack:** React 19, TypeScript strict, zustand, zod v3, Dexie 4, Vitest + Testing Library.

## Global Constraints

- Aucune nouvelle dépendance (pas d'i18next, pas de react-intl).
- TS strict : `noUnusedLocals` et `noUnusedParameters` actifs — aucune variable inutilisée, même dans les tests.
- zod v3 : `.default()` accepte une fonction (utilisé pour la détection dynamique).
- Vitest sans globals : importer `describe/expect/it/beforeEach/...` depuis `'vitest'`. Tests DB : `import 'fake-indexeddb/auto'` + `beforeEach` qui vide `db.tables`.
- Commentaires de code en français ; messages de commit conventionnels en anglais.
- `LANGUAGE_LABELS` (`src/texts/types.ts`) reste tel quel : les sélecteurs de langue affichent des autonymes (« Français », « English ») quelle que soit la langue d'interface — décision révisée par rapport à la spec.
- Les ids de tiers (`'argent'`…), de catégories (`'vitesse'`…) et les contenus du corpus ne changent jamais.
- Commandes : tests ciblés `npx vitest run <fichiers>` ; suite complète `npm test` ; build `npm run build` (inclut `tsc --noEmit`).
- Chaque tâche se termine par : tests ciblés verts + `npm test` vert + commit. La suite doit rester verte entre les tâches.

`src/i18n/detect.ts` :

```ts
import type { UiLanguage } from './types';

/**
 * Langue d'interface par défaut : français si le navigateur est francophone,
 * anglais sinon (public international). Gardée pour les environnements sans navigateur.
 */
export function detectUiLanguage(): UiLanguage {
  if (typeof navigator === 'undefined' || typeof navigator.language !== 'string') return 'en';
  return navigator.language.toLowerCase().startsWith('fr') ? 'fr' : 'en';
}
```

`src/i18n/translate.ts` :

```ts
import { en } from './en';
import { fr, type TranslationKey } from './fr';
import type { Params, UiLanguage } from './types';

const DICTS: Record<UiLanguage, Record<TranslationKey, string>> = { fr, en };

/** Traduction pure + interpolation `{token}` ; token non fourni = laissé tel quel. */
export function translate(lang: UiLanguage, key: TranslationKey, params?: Params): string {
  const template: string = DICTS[lang][key];
  if (!params) return template;
  return template.replace(/\{(\w+)\}/g, (raw, name: string) =>
    params[name] === undefined ? raw : String(params[name]),
  );
}
```

`src/i18n/index.ts` :

```ts
import { useCallback } from 'react';
import { useSettings } from '@/state/settingsStore';
import type { Tier } from '@/scoring/league';
import type { TranslationKey } from './fr';
import { translate } from './translate';
import type { LocalizedText, Params, UiLanguage } from './types';

export function useUiLanguage(): UiLanguage {
  return useSettings((s) => s.profile.uiLanguage);
}

/** Closure de traduction mémoïsée sur la langue courante. */
export function useT(): (key: TranslationKey, params?: Params) => string {
  const lang = useUiLanguage();
  return useCallback((key: TranslationKey, params?: Params) => translate(lang, key, params), [lang]);
}

export function localeFor(lang: UiLanguage): string {
  return lang === 'fr' ? 'fr-FR' : 'en-US';
}

/** Formateur de dates dans la locale de l'interface (recréé par rendu, coût négligeable ici). */
export function useDateFormatter(options: Intl.DateTimeFormatOptions): Intl.DateTimeFormat {
  return new Intl.DateTimeFormat(localeFor(useUiLanguage()), options);
}

/** Choisit la langue d'un texte porté par la donnée (succès). */
export function pick(text: LocalizedText, lang: UiLanguage): string {
  return text[lang];
}

export function tierLabel(tier: Tier, lang: UiLanguage): string {
  return translate(lang, `tier.${tier}` as TranslationKey);
}
```
