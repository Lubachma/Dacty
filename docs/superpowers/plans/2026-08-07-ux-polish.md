# Polish UX — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Quatre mini-fixes UX : titres d'onglet par route, pause de run à la sortie de
page, cap de 3 toasts, contraste accent AA.

**Architecture:** map route→titre dans `Layout`, hook `usePauseRunOnUnmount` partagé par
les 3 pages de run, borne dans `toastStore.push`, deux tokens d'accent (normal + strong)
dans `index.css` épinglés par un test de contraste WCAG.

**Tech Stack:** React 19, Tailwind 4 (`@theme inline`), zustand, vitest + jsdom.

Spec : `docs/superpowers/specs/2026-08-07-ux-polish-design.md`

## Global Constraints

- TypeScript strict avec `noUnusedLocals` / `noUnusedParameters`.
- Commentaires en français, commits en anglais (conventional commits).
- Les `bg-accent` SANS texte blanc (barres de progression, curseur `TypingArea`,
  `Toggle`) ne changent pas.
- Thème clair : aucun changement de couleur (`--accent` reste `#6a4dff`).

```ts
import { useEffect } from 'react';
import { useRunStore } from '@/state/runStore';

/**
 * Met la run en pause quand on quitte la page : le chrono ne tourne pas pendant la
 * navigation (le temps de pause est exclu par pausedMs). pause() est un no-op si la
 * run n'est pas en cours.
 */
export function usePauseRunOnUnmount(): void {
  useEffect(
    () => () => {
      useRunStore.getState().pause();
    },
    [],
  );
}
```

- [ ] **Step 1: Écrire le test qui échoue** — `src/ui/contrast.test.ts`

```ts
import { describe, expect, it } from 'vitest';

// Épingle les ratios WCAG 2.1 des paires de couleurs du thème (src/index.css) :
// tout texte doit rester ≥ 4,5:1 (AA). Mettre à jour index.css casse ce test.
function luminance(hex: string): number {
  const srgb = [1, 3, 5].map((i) => parseInt(hex.slice(i, i + 2), 16) / 255);
  const lin = srgb.map((v) => (v <= 0.04045 ? v / 12.92 : ((v + 0.055) / 1.055) ** 2.4));
  return 0.2126 * lin[0] + 0.7152 * lin[1] + 0.0722 * lin[2];
}

function ratio(a: string, b: string): number {
  const [hi, lo] = [luminance(a), luminance(b)].sort((x, y) => y - x);
  return (hi + 0.05) / (lo + 0.05);
}

describe('contraste du thème (WCAG AA)', () => {
  it('thème sombre : accent sur fond et blanc sur accent-strong ≥ 4,5:1', () => {
    expect(ratio('#8064ff', '#0b0f14')).toBeGreaterThanOrEqual(4.5); // text-accent
    expect(ratio('#ffffff', '#6a4dff')).toBeGreaterThanOrEqual(4.5); // boutons bg-accent-strong
  });

  it('thème clair : accent sur fond et blanc sur accent ≥ 4,5:1', () => {
    expect(ratio('#6a4dff', '#f6f8fa')).toBeGreaterThanOrEqual(4.5); // text-accent
    expect(ratio('#ffffff', '#6a4dff')).toBeGreaterThanOrEqual(4.5); // boutons bg-accent-strong
  });
});
```
